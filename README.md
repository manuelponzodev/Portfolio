# Manuel Ponzo — Portfolio

Portfolio personal en español. Estética oscura y editorial (Inter Tight + Instrument Serif + DM Mono, acento naranja), con:

- Saludo inicial en los idiomas que hablo (Hola · Hello · Bonjour · Hallo).
- Retrato en blanco y negro que revela el color bajo el cursor.
- Texto de intro que se enciende palabra por palabra con el scroll.
- Proyectos contados como capítulos: un escenario fijo cuya animación cambia según el paso de la historia que estás leyendo.
- Scroll suave con [Lenis](https://github.com/darkroomengineering/lenis) desde CDN (si no carga, usa el scroll nativo).

## Abrir localmente

```sh
node serve.cjs
```

Después abrí http://localhost:8000.
